# Papers

这里整理我后续阅读论文时的精读笔记。和 `RoboTwin/` 不同，这一部分不以源码仓库为中心，而是以**论文主题、方法思想、实验结论与复习回查**为中心来组织。

## 为什么单独建 Papers

`RoboTwin/` 更适合放：

- 仓库实现
- 训练 / 推理流程
- 数据流与代码定位

而 `Papers/` 更适合放：

- 论文精读
- 方法设计动机
- 实验与结论整理
- 附录补充与复习提纲

把两者分开之后，后面复习时会更清楚：

- 想看“代码怎么实现”时去 `RoboTwin/`
- 想看“论文到底说了什么”时来 `Papers/`
